## What you'll find here

Agosto foi dominado pelo ciclo diário de rotinas de manutenção (oss-radar-v2, vault-health, journal-audit, meta-skill-improver, update-check), quase todas `completed` sem incidentes — sinal de infraestrutura estável. O evento mais notável do mês foi o travamento do Mac mini por uma assertion CloudKit presa (`AccessibilityUIServer`, conta caroline), que expôs as limitações de privilégio do bot (sem sudo, sem automação GUI via TCC) e gerou uma memória durável sobre essas restrições. Fora isso, o mês foi rico em atividade de agentes especializados registrada no journal: parmeirense corrigiu um bug de seleção de imagem de capa no pipeline `palmeiras-feed-v2`; crypto-bro silenciou notificações de skip do `defiverso-daily-scout-v2` via flag `notify_skip`; mexc-bot investigou (mas não aplicou) um bug de sizing que travava execuções de ordens reais; e contador/contador-pj tiveram o mês mais movimentado, registrando contas no Notion, construindo uma knowledge base de produtos financeiros (cartões de crédito) e investigando gastos anômalos com Uber.

## Decisions
- Bot não tenta reiniciar o Mac mini autonomamente — sem sudo sem senha, TCC bloqueia automação GUI; reboot exige `sudo shutdown -r now` no Terminal do usuário
- `notify_skip: false` via frontmatter é a via preferida para silenciar rotinas, em vez de alterar o harness
- Fix do mexc-bot (sizing, maxVol, erros permanentes) fica pendente de go-ahead explícito por envolver dinheiro real
- Anexos de comprovantes no Notion devem usar File Upload API, nunca URL externa do Telegram
- Hard filters de seleção de imagem agora são absolutos mesmo sem candidato alternativo (parmeirense)

## Lessons
- Erros de API que devem interromper retry (ex. MEXC 2051/2005) precisam estar explicitamente na lista de códigos permanentes, senão geram retries inúteis
- Processos travados entre contas de usuário (UID diferente) exigem `sudo` manual — automação do bot não alcança essa camada
- Booleanos em frontmatter YAML devem ser reais (`false`), não strings (`"false"` é truthy)

## Carry-forward

- Validar em produção o novo caminho `rejected_all` do image-review no `palmeiras-feed-v2`
- Confirmar pagamento/débito de faturas Nubank e Itaú de agosto no Notion
- Decisão pendente sobre manter/cancelar Clube Smiles considerando ganho extra de milhas via Uber
