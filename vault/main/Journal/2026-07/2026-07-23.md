## Session Snapshot — 2026-07-23 03:30

Bot dev session via Telegram — two fixes shipped, both committed to `main`.

### Topics discussed
- **Silent idle auto-compact.** The "🔄 Auto-compact (sessão … inativa Xh)" message that fires when a session sits idle ≥4h. Found it was already sent with `disable_notification=True` (silent, no sound) since v3.27.0 — so it never rang, but it still landed in the chat and bumped the unread count. Vinicius asked to suppress it entirely.
- **"Scheduler travado" false alarm.** Telegram received "⚠️ Scheduler travado! Sem heartbeat há 465s (processo vivo). Reiniciando o Claude Bot...". Investigated via bot.log + `last` + pmset: the Mac shut down at 03:13 and rebooted at 03:17 (no `.panic` files → not a kernel panic; looks like an auto-update / scheduled reboot). The scheduler thread froze during the pre-shutdown window, so the heartbeat went stale (465s) and the watchdog cried "travado" — a false positive. That spurious restart also killed the in-progress turn, which is why the journal-consolidation request got resent as "crash/restart".

### Decisions
- Fully suppress the idle auto-compact Telegram message; keep the `bot.log` record and leave the 🧹 idle-CLEAR notification intact.
- The watchdog must not restart on a SINGLE stale-heartbeat reading — a transient freeze (sleep/wake, load spike, pre-shutdown) is not a deadlock. Guard with boot-grace + debounce.
- No `BOT_VERSION` bump for `bot-watchdog.sh` — it's standalone launchd infra, not the versioned bot process.

### Actions
- `a75b660` — fix: run passive idle auto-compact silently (v3.78.1 → 3.78.2). Removed the `_send_idle_notification` call in `_check_idle_sessions`. Used selective per-hunk staging because the file already carried a separate uncommitted PHOTO/`send_photo` workstream that had to stay untouched.
- `699c9fb` — fix(watchdog): boot-grace (300s) + debounce (2 consecutive stale checks via `.watchdog-stale-since`) in `bot-watchdog.sh`; new `system_uptime_secs()` parses `kern.boottime` with the absolute `/usr/sbin/sysctl` path.

### Notes / durable facts
- `kern.boottime` prints `{ sec = <epoch>, usec = … }` — a naive `.*sec = ` regex captures `usec`; anchor the match on `{ sec = `.
- launchd jobs run with a minimal PATH → always use absolute tool paths in the watchdog/scripts (`/usr/sbin/sysctl`, `/usr/sbin/lsof`).
- A macOS reboot's pre-shutdown window freezes app threads → stale heartbeat → false watchdog trip. Boot-grace + debounce is the mitigation.
- Effect timing: the watchdog fix is live on its next 60s launchd tick (each run re-reads the script); the silent-compact change needs a bot restart to take effect.
