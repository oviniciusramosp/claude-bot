## What you'll find here

Semana densa com três frentes principais simultâneas. O bot recebeu a migração de formatação MarkdownV2→HTML (v3.72.0), eliminando o problema crônico de mensagens caindo para plain text. O MEXCBot evoluiu de v0.11 a v0.16 com classificação de BreakEven (|R|≤0.15), card de mês, resolved-only win/loss, estratégias responsivas no mobile, mensagem fixa de status no Telegram, tema light/dark/system e i18n PT→EN — além de três bugfixes estruturais (resolução dinâmica de símbolos, duplicatas de notificação, diagnóstico do overcount de PnL no trade #242). Em paralelo, o app web CryptoBro foi construído do zero como SPA standalone (FastAPI + React), com gráfico BTC e EMAs históricas via CSV de 863 semanas, prediction bands com acurácia histórica ✓/✗, multi-ativo e geração de posts. Também foi criado o agente secretaria e realizado um audit do hermes-agent identificando threat patterns e think scrubber como candidatos de adoção.

## Goals

- Migrar Telegram formatting de MarkdownV2 para HTML no claude-bot (v3.72.0)
- Auditar hermes-agent para identificar features aplicáveis ao claude-bot
- Evoluir dashboard MEXCBot com BE band, status pin e polimento de UI
- Construir app web CryptoBro como dashboard standalone
- Criar agente secretaria com suporte a Google Calendar
- Corrigir bugs MEXCBot: resolução de símbolo, duplicatas Telegram, PnL overcount

## Decisions

- `parse_mode="HTML"` como default no bot; MarkdownV2 mantido como opt-in explícito
- Pipeline `crypto-write` removido; escrita direta via skills `crypto-writer` + `notion-post-rules`
- CryptoBro como app standalone (não embutir no WalletRadar); tunnel público com PIN
- MEXCBot: `BREAKEVEN_R_BAND = 0.15`, classificação BE ortogonal ao mecanismo TP1+BE do `real_trader`
- Threat patterns (alta prioridade) e think scrubber (média) identificados no hermes-agent — não implementados ainda
- Secretaria: OAuth2 self-hosted stdlib-only para Calendar, não API key nem connector claude.ai

## Progress

- Bot v3.72.0: novos helpers `_markdown_to_html`, `_md_prose_to_html`, `_strip_html_tags`; ~25 locais MDv2 limpos
- MEXCBot v0.11–v0.16: BE band (`classify_wl`), card de mês no dashboard, resolved-only winloss, strategies mobile (sticky col + scroll), status pin edit-in-place, tema light/dark/system, i18n eliminando PT residual; commits isolados por frente
- MEXCBot bugs: fallback dinâmico de símbolo via API MEXC (cache 1h), dedup de notificações de close, diagnóstico fechado do overcount PnL #242 (on_tp1_fill não acumula partial_qty)
- CryptoBro: FastAPI :8799 + React SPA buildada; BTC chart + EMAs (50/100/200/250w/450w Low via CSV histórico); prediction bands com ✓/✗ passadas; multi-ativo; news com tags dinâmicas, paginação e busca; post generation via opus
- Secretaria criada (estrutura v3.5 completa, OAuth2 planejado, aguardando credenciais GCP)
- Hermes-agent auditado via `gh api`; PR #2044 descartado (arquitetura incompatível)
