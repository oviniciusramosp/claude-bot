## What you'll find here
Semana dominada por estabilidade e migrações: recuperação pós-reboot do Mac Mini (6/8 serviços automáticos; PintchTab e CryptoBro com workarounds manuais documentados), remoção definitiva do GLM 5.1 e adoção do Opus como modelo default no bot e OpenClaw. O comando `/morri` foi implementado no claude-bot (v3.75.0) com scaffold de base de legado no vault — docs em texto simples legíveis sem IA, segredos como ponteiros, instância pessoal gitignored. MEXCBot recebeu fix crítico do pin de status Telegram (v0.17.2, tri-state `edit_message_text`) e o problema recorrente de whitelist IP da MEXC foi encerrado com whitelist vazia. CryptoBro ganhou visualizações avançadas de ciclos BTC (log-scale, gap fill diário 2012, recovery segments cross-ciclo). Agentes contador e contador-pj processaram os principais boletos de junho no Notion.

## Decisions
- `DEFAULT_MODEL = "opus"`, fallback chain `opus → sonnet → glm-4.7 → haiku` (GLM 5.1 removido); `update-check` migrada para `sonnet`
- Whitelist IP MEXC mantida vazia (chaves sem saque); lembrete Calendar para 2026-09-15 renovar chaves API
- `edit_message_text` MEXCBot: recria mensagem só em `gone`, nunca em falhas transitórias (429/5xx/timeout)
- Segredos no vault Legacy apenas como ponteiros; `vault/main/Legacy` gitignored; senha do Mac não escrita literalmente
- Daily interpolation para gap Nov 2012–Mar 2013 no CryptoBro (frequência uniforme garante posicionamento correto de marcadores)
- Dashboard "129 trades" AutoTrader está correto — métrica contrafactual, não ledger executado
