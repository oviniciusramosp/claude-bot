## 13:05 — Telegram formatting bugs patched (v3.68.3)

- Three recurring formatting bugs: tables not rendering, `**bold**` not working, spurious strikethrough in messages
- Root cause: `~` greedy matching treated any two tildes in text (e.g. `~/claude-bot/` paths) as strikethrough markers, escaping inner `*` characters
- Fixed: `~` always escaped as `\~`; `_convert_md_tables` added to convert markdown tables to aligned code blocks before MDv2 sanitizer runs
- Bot bumped to v3.68.3; ClaudeBotManager Info.plist updated
